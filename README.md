# Matt-Public

> 我的第一个**公开**仓库 —— 用来练习开源协作、体验 GitHub 各种文件存放能力。
>
> 账号：[Matt163ly](https://github.com/Matt163ly) · 类型：公开（Public）· 默认分支：`main`

## 这个仓库用来做什么

- 体验真正的**开源协作**：任何人都能看到、Fork、给你提 PR
- 测试 GitHub 能存哪些东西：代码、文档、图片、数据、网页……
- 作为你练习 add / commit / push / Pull Request 的公开 sandbox

## 和私有仓库 Matt 的区别

| | Matt（私有） | Matt-Public（公开） |
|---|---|---|
| 谁能看 | 只有你和协作者 | 全世界 |
| 谁能提 PR | 需先加协作者 | 任何人都能 Fork 后提 PR |
| 适合 | 私人项目 | 开源项目、作品展示 |

想练"别人给我提 PR"，用这个公共仓库最合适。
